# 输出模式（第 6 步 · 形态选择与模板）

## 模式选择启发

| 用户信号 | 输出模式 |
|---|---|
| 没说（默认） | 分析体 |
| 「怎么回 / 回怼 / 帮我回复」 | 反驳卡片 |
| 「视频 / 口播 / 文案 / 脚本」 | 口播稿 |
| 贴的是整场对话、辩论、多人互喷 | 辩论简报 |
| 「教我 / 怎么识别 / 学一下」 | 教学体 |

可组合（如"分析这场辩论，再给我一版口播稿"）。模式不确定时用分析体，结尾一行提示可用其他模式。

## 模式一 · 分析体（默认）

```markdown
# 拆招：<主题>

**原话**：>「……」
**论证还原**：结论「…」← 理由A、理由B（隐含前提：…）

这段话里藏着 **N** 个逻辑谬误：

## 1. <中文名>（English）· 置信度：高 ⚠承重
> 「<最小充分片段>」

**机制**：……
**举证**：……
**反驳句**：……

## 2. ……

## 总评
- 承重谬误：#…
- 事实错误/价值分歧（非谬误）：…
- 论证强度：……
```

## 模式二 · 口播稿

**结构**：钩子 → 原话 → 逐条 → 收尾

1. **钩子**：「短短一段话，居然藏着 N 个逻辑问题」——N 实数实报，不夸大
2. **原话**：完整引用，给足画面感
3. **逐条展开**，每条三拍：
   - 设问引入（「先看第一句，问题出在哪？」）
   - 拆解（口语化机制：「翻译一下就是……」「他把 A 悄悄换成了 B」）
   - 举证 + 金句收尾（归谬 / 平行替换优先，最能出效果）
4. **收尾**：承重谬误点题 + 一句立论（正确版本该怎么想）

**口语规则**：每条机制 ≤ 3 句；设问推进节奏；术语必须跟白话；数据引用口播中必须带「有据可查」或直接略去。裁决纪律全部不变。

## 模式三 · 反驳卡片

给用户**直接发出去**的回复，实战非教学：

```
≤ 3 句，三选一或组合：
① 认领（可选）：「你说的 X 我同意」
② 一记最重反驳：归谬或平行替换，只打承重谬误，不列举全部
③ 一句立论：「真正该比的是……」
```

**纪律**：不教学、不贴标签（不出现"你这是XX谬误"）、不纠小错；语气按用户与对方关系选（克制 / 锋利），默认克制。

## 模式四 · 辩论简报

多人对话 / 辩论赛 / 网络骂战：

```markdown
# 辩论简报：<议题>

## 各方还原
### <说话人A>
论证还原卡（见 reconstruction.md）+ 谬误记分（编号列表）
### <说话人B>
……

## 对比
| | A | B |
|---|---|---|
| 承重谬误 | #1 | 无 |
| 论证完整性 | … | … |
| 事实底座 | … | … |

## 裁决
逻辑胜负 + 理由 + 双方最强补强路径（各自补什么就能赢）
```

**纪律**：裁决只评逻辑不评立场；每方都给"最强补强路径"，不做单向审判。

## 模式五 · 教学体

用户想学识别能力时：

- 每条谬误附**识别练习**：在原文标出锚点，让用户先猜再看答案
- 附**举一反三**：同一个谬误换三个场景的长相
- 结尾给「30 秒自查法」：遇到可疑话语时先问的三个问题（结论是什么？→ 隐含前提补全后还谬吗？→ 拆掉它结论塌吗？）
