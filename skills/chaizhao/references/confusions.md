# 易混谬误辨析与元谬误

两个用途：**定罪时**区分长相相似的双胞胎；**收尾时**防止分析者自己犯元谬误。

## 高频混淆对

判别方法：对每对给出一个判别问题，答案落在哪边，定罪就在哪边。

| 混淆对 | 判别问题 |
|---|---|
| 稻草人 D4 vs 钢人操作 | 对方**原话**被改写了吗？改写了再打 = D4；补强后再分析 = 钢人（正常操作，不是谬误） |
| 人身攻击 D1 vs 质疑资质（E1 边界） | 攻击的是**人品/身份**，还是**相关领域的资质**？后者是证言可信度评估，不是谬误 |
| 虚假因果 C1 vs 滑坡 C3 | 单步的假因果，还是**多步链条**中存在无必然环节？一步之差分 C1/C3 |
| 以偏概全 B1 vs 轶事证据 B2 | 在**泛化结论**（"XX 人都这样"），还是在**对抗统计**（"我认识一个…所以数据是假的"）？ |
| 红鲱鱼 F5 vs 苦难奥林匹克 F6 | 泛泛地转移话题，还是特定的**"比惨"式**转移（用更大的苦难取消正当性）？ |
| 偷换概念 A1 vs 范畴错置 A5 | 同一个词**含义**变了（A1），还是从一层真相**推不出**另一层结论（A5）？ |
| 诉诸情感 E3 vs 诉诸动机 D3 | 用**情绪加压**（愧疚/恐惧/崇高感）代替论证，还是用**"他别有用心"**抹黑论点来源？ |
| 循环论证 F2 vs 断言重复 F8 | 前提里**藏着结论**（F2），还是**没有任何前提**、纯靠重复（F8）？ |
| 你也一样 D2 vs whataboutism | "你也有错"是在**回应指控本身**（D2），还是在**转移议题**（D2+F5 复合，标注复合）？ |
| 破窗 C2 vs 单一原因 C5 | 把**破坏当收益**（C2），还是把多因结果归到**一个原因**（C5）？ |
| 否定后件 MT（**有效**） vs 否定前件 H2 | 从「非 Q」回推「非 P」**有效**；从「非 P」推「非 Q」**无效**——箭头方向别搞反（对照表见 formal-checks.md） |
| 虚假等价 A9 vs 你也一样 D2 | 在**比较性质**（"都一样"，A9），还是在**豁免行为**（"他也干了所以不算错"，D2）？ |

**同处多犯时**：一处文本取**最准确的一个**名；确属复合结构（如 whataboutism）才标注复合，不堆砌。

## 元谬误（分析者自己犯的错）

### 谬误谬误（Fallacy Fallacy）——最重要的一条

**推理有谬误 ≠ 结论为假。**稻草人打输了，不代表对方结论是对的；滑坡断裂了，不代表坡底的事不会发生。

**输出纪律**：总评里必须包含一条**独立的结论判断路径**——"该结论的真假需要什么证据来独立判定"，与谬误清单分开。

### 谬误警察

只贴标签不分析。每条定罪必须能**一句话讲出断裂点**；讲不出断裂点的标签，删。

### 过度定罪

钢人补全后消失的"谬误"，要**主动撤销**，不要为了凑 N 留着。置信度不足的进"存疑"，默认不列。

### 语域误判

把玩笑、反讽、修辞、仪式性表达按严格论证标准拆。拆之前先回 reconstruction.md 第 0 步判语域；判错的定罪全部作废。

### 双向检验

换一个**立场与你相同**的人说同样的话——你还定罪吗？不定罪，说明你的判定被立场污染了，重审。

## 定罪决策树（速查）

```
1. 这段话承担论证功能吗？（语域判定）
      否 → 不进清单，注明语域
      是 ↓
2. 有可辨认的推理断裂吗？（钢人补全后再看）
      否 → 不进清单（可能是事实错误/价值分歧/论据薄弱，另标）
      是 ↓
3. 断裂属于哪类？——含显式条件句/三段论/概率叠加先查 formal-checks.md（先形式后内容）；其余查 fallacies.md；拿不准查上方混淆对
      ↓
4. 拆掉它，结论塌吗？
      塌 → 标 ⚠承重；不塌 → 装饰性
      ↓
5. 置信度：能逐字引用 + 能一句话讲出断裂 = 高
          讲得清但有更善意的替代解读 = 中
          再弱 = 存疑（默认不列，穷尽模式才出）
```
