# 高发误判与定罪自查（第 3 步 · 定罪前必过）

**每一条定罪，先过这一关。**误判的代价比漏判高：错报一条，整份分析的可信度全赔进去。

## 十三高发误判

### 1. 情感诉求 ≠ 谬误
与议题**相关**的情感证据（受害者的证词、当事人的陈述）是合法论据，只是不充分。只有**无关的情感操控**（扣帽子、道德绑架、恐吓）才定 E3。
**纠正动作**：先问"这个情绪和论题有没有关系"，再问"它有没有承担超出其能力的证明功能"。

### 2. 诉诸权威 ≠ 谬误
相关领域专家 + 领域共识存在 + 议题超出普通人判断力 → 引用专家是**正当证据**。
**谬误版**：跨领域引用、少数派冒充共识、一票定音拒绝其他证据。

### 3. 类比用于说明 ≠ 谬误
类比帮人理解不谬；只有**承担证明功能**且结构断裂才定 A3。
**纠正动作**：问"删掉这个类比，论证还剩什么"——还完整，类比只是修辞。

### 4. 简化 ≠ 谬误
口头表达、字数限制下的省略前提是常态。先钢人补全再判定；补全后不谬的撤出清单。

### 5. 事实错误 ≠ 谬误
数据错了是**事实问题**，单独列在"事实核查点"，不进谬误清单——除非对方用错误事实继续完成错误推理（那就只定推理那段）。

### 6. 价值分歧 ≠ 谬误
「更看重自由还是安全」「该不该为了 X 牺牲 Y」是价值观冲突。标注为**价值分歧**，不定罪，可指出双方各自的价值前提。

### 7. 夸张、反讽、玩笑 ≠ 谬误
修辞性夸大只在**被当作论据使用**时进入定罪。先判语域（reconstruction.md 第 0 步）。

### 8. 弱归纳 ≠ 谬误
结论强度与证据**匹配**的常识归纳（"摸过的蛇大多咬人"）不必打回。只有结论强度**明显超出**证据承载时才定 B1/B2。

### 9. 案例枚举只能建立相关性
列举多个同类案例（"某人如此，某人也如此"）只构成**相关性联想**，不能写成因果证明。引用此类论证时必须降级标注为「相关性举证」。

### 10. 谬误谬误（Fallacy Fallacy）
推理失败 ≠ 结论为假。**总评必须给结论独立的真假判断路径**。详见 confusions.md 元谬误一节。

### 11. 语域误判
把脱口秀当论文拆、把客套当论证拆。定罪前回看语域标签；拿不准时在输出开头声明"按严格论证标准分析"。

### 12. 转写与翻译失真
分析对象若是音频转写、机器翻译文本，先校订明显失真（人名、断句、代词）再分析；无法校订的关键处标注「原文存疑」，不在失真处定罪。

### 13. 形式有效 ≠ 谬误
MP（肯定前件）、MT（否定后件）、析取三段论、假言三段论都是**有效推理**——别把「否定后件」误判成「否定前件」（H2），别把合法的逆否推理当谬误。
**纠正动作**：含条件句/三段论的文本先做形式化 → 对照 formal-checks.md 的有效形式表 → 确认**结构无效**才定 H 类。

## 定罪前自查清单（八问）

```
□ 1. 我钢人了吗？——隐含前提按最善意补全后，它还谬吗？
□ 2. 我引用最小充分片段了吗？——引不出来的，删
□ 3. 断裂点能一句话讲出吗？——讲不出的，删
□ 4. 换立场相同的人说这话，我还定罪吗？——不会，就是立场污染，重审
□ 5. 这是事实问题或价值分歧吗？——是，移出谬误清单，单独标注
□ 6. 我把结论判死刑了吗？——推理错 ≠ 结论假，总评里给独立判断路径
□ 7. N 有没有凑数？——存疑的不列，装饰性的不标承重
□ 8. 形式有效吗？——MP/MT 等有效形式不是谬误（对照 formal-checks.md）
```

八问全过，才允许写进清单。
