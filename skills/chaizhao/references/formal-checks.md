# 形式检验（显式推理结构的核查工具）

**何时用**：文本含显式推理结构——「如果…那么…」「只要…就…」「所有…都…」三段论、概率叠加、析取选择——先做形式检验，再查非形式谬误。这是"准确定位"的第一道闸：**先判形式是否有效，再谈内容**。形式无效直接定 H 类；结构有效再查 A–G 类。

## 一、自然语言形式化（四步）

1. **切原子命题**：把每句话缩写为 P、Q、R…
2. **标联结词**：认出"如果/只要/只有/除非/要么/并且/或者"
3. **写出形式**：把句子替换成符号式
4. **对照下表**判有效性——结构无效即形式谬误，结构有效再查 A–G

### 条件句标志词对照

| 自然语言 | 形式 | 注意 |
|---|---|---|
| 「如果/只要/倘若 P，就 Q」 | P→Q | P 是 Q 的**充分**条件 |
| 「只有 P，才 Q」 | Q→P | P 是 Q 的**必要**条件——箭头方向相反，高频出错点 |
| 「除非 P，否则 Q」 | ¬P→Q（等价 P∨Q） | "除非"把 P 变成"避免 Q 的唯一途径" |
| 「要么 P 要么 Q」 | P∨Q | 默认**相容**析取（可同时成立）；明确"不可兼得"才是不相容 |
| 「所有 S 都是 P」「凡是 S 都 P」 | 全称：S⊆P | 三段论材料 |

## 二、条件句与析取：有效 / 无效对照表

| 前提 | 结论 | 名称 | 判定 |
|---|---|---|---|
| 若 P 则 Q；P 成立 | ∴ Q | 肯定前件 MP | ✓ **有效** |
| 若 P 则 Q；Q 不成立 | ∴ P 不成立 | 否定后件 MT | ✓ **有效** |
| 若 P 则 Q；Q 成立 | ∴ P | 肯定后件 AC | ✗ H1 |
| 若 P 则 Q；P 不成立 | ∴ Q 不成立 | 否定前件 DA | ✗ H2 |
| P 或 Q；非 P | ∴ Q | 析取三段论 DS | ✓ **有效** |
| P 或 Q；P | ∴ 非 Q | 肯定析取 | ✗（相容析取下无效——P、Q 可同真） |
| 若 P 则 Q；若 Q 则 R | ∴ 若 P 则 R | 假言三段论 HS | ✓ **有效** |
| 若 P 则 Q；若 R 则 S；P 或 R | ∴ Q 或 S | 构造二难 | ✓ **有效**（拆二难只能质疑前提或找第三选项，不质疑形式） |

**方向口诀**（防 H1/H2 误判的高发点）：
- 从「非结果」回推「非原因」——**有效**（MT）
- 从「非原因」推「非结果」——**无效**（H2）
- 从「结果」回推「原因」——**无效**（H1）
- 一句话：**箭头只能顺着走、逆着否定；逆着走、顺着否定都是错的。**

## 三、三段论检验

**文氏图三步**：画两个/三个圈 → 按前提涂区域 → 检查结论是否已被图保证。图不保证结论 ⇒ 形式无效。

**高频规则**：
1. **中项至少周延一次**——否则 H3（中项不周延）。检查：中项（两前提共享的词）是否在任一前提中覆盖了类的全部成员。
2. **四词项检查**——数一数形式里到底有几个概念：中项在两个前提中**含义**必须同一（「老鼠药是药；药是好的」的"药"一词两义 ⇒ H4，地基是 A1 偷换概念）。
3. 前提否定 ⇒ 结论必须否定；双否定前提推不出任何东西。

**长尾速查**（低频，出现频率低，检出后按名归位）：不周延大项（illicit major）、不周延小项（illicit minor）、双否定前提、否定前提得肯定结论、存在谬误（全称前提推存在结论）、模态谬误（把"必然"与"实然"混写）。

## 四、概率形式速查

| 规则 | 拆什么 |
|---|---|
| P(A∧B) ≤ min(P(A), P(B)) | 合取谬误 G6——"更具体的故事更可能"永远为假 |
| P(H\|E) ≠ P(E\|H) | 检察官谬误（G1 变体）——证据下嫌疑 ≠ 嫌疑下证据 |
| 可能 ≠ 必然 | 诉诸可能性 H5——"有概率"推不出"会发生" |
| 独立事件无记忆 | 赌徒谬误 G2 |

## 五、形式谬误 vs 非形式谬误的分界

- **结构无效 ⇒ H 类**：与内容真假、话题、情绪全部无关——把论证符号化后形式不成立，就是形式谬误
- **结构有效但前提/语境有问题 ⇒ A–G 类**：形式是好的，坏在前提假（事实问题）、前提无关（D/E 类）、用词漂移（A 类）、数据误用（G 类）
- **定罪顺序**：先形式后内容。形式无效 → 直接定 H（不必再贴 A–G 标签，除非词义漂移是地基——标注 H4（联动 A1）这类复合）
- **自然语言很少是严格形式**：形式化之前先钢人——按"最善意符号化"原则补全省略前提、选最有利的量词解读；**形式化本身就是一次钢人操作**。补全后形式有效的，退回非形式检验
