# 反驳工程（第 5 步 · 从定罪到能打出去）

定罪是分析，反驳是工程——要选打击点、选强度、选语气。本文件覆盖：选打击点 → 强度阶梯 → 提问式反驳 → 礼貌梯度 → 反驳句写作规范 → 防守。

## 三个打击点（按破坏力与风险排序）

| 打击点 | 打什么 | 何时用 | 风险 |
|---|---|---|---|
| **拆推理**（逻辑层） | 指出推理断裂 | 断裂清晰可见时；**默认选项** | 低 |
| **拆前提**（事实层） | 指出前提为假 | 前提明显可证伪时 | 中——会拖入事实核查战 |
| **拆框架**（议题层） | 重新定义问题本身 | 议题被偷换、或对方所有论点都建立在错误问题上时 | 高——可能被指"回避问题"，必须一句话讲清为什么换框架 |

**选点原则**：一次只打一个点。三个都打等于没打。

## 反驳强度阶梯（弱 → 强）

1. **指认**：「这里是滑坡谬误」——只贴标签，教学用，实战几乎无用
2. **讲断裂**：「从 A 到 B 这一步凭什么必然？」——分析用
3. **归谬 / 反例 / 平行替换**——实战主力（见 ammunition.md）
4. **立论替代**：给出正确推理 + 自己的结论——终结用，成本最高

实战从第 3 级起步；第 1–2 级留给教学场景。分析体输出中的「反驳句」按第 3 级标准写。

## 提问式反驳（苏格拉底式）

陈述告知，提问逼迫。把反驳句转成对方**必须回答**的问题：

- 转写规则：断言句 → 「凭什么……」「照这个逻辑，那……吗」「这个数字从哪来的」「你说的 X 是指甲还是乙」
- **上限纪律**：连环三问为限，超过就变成审问，听众会同情对方
- 每类谬误的「必杀一问」见 fallacies.md 各条目的反驳句，按此节规则按需转成疑问式

## 礼貌梯度（对事不对人的操作化）

- **场合感知**：私聊留面子 / 群聊给台阶 / 公开写作对读者不对对手
- **三个转写动作**：
  1. 「你错了」→「这里少了一块」
  2. 不对动机出拳（对方收没收钱，与推理对错无关）
  3. 给对方留修正路径：「只要补上 X，这个论证就成立」——风度和杀伤力不冲突

## 反驳句写作规范

- **一句内完成**；有画面；零术语（普通听众）或「术语 + 白话」双版本
- **检验标准**：对方听到后**能做什么**？如果只能恼羞，重写；如果能回答、能补证据、能认错，就是好反驳
- 优先用弹药库里已质检过的句子，不要现场发明没把握的类比

## 防守（被谬误攻击时）

用户被扣帽子、被转移话题、被逼自证时的标准动作：

- **不接新框架**：「这个问题回头谈——先回答原来的问题」（对红鲱鱼 / 苦难奥林匹克）
- **不自证**：「举证责任在你，不在我」（对转移举证责任 / 井中投毒）
- **拆稻草人**：「我没这么说。我们回到我的原话」
- **承认小错换大局**：无关紧要的让步痛快给出，换议题主导权
- **不追击人**：对方人格崩溃式的失态，不复读、不嘲讽，钉回论点即可
