# 举证弹药库（八式 · 构造方法与质检标准）

**通则**：
- 每条定罪配 1–2 发弹药，选最有力的，不堆砌
- 弹药的唯一使命是**证明断裂真实存在**，不是炫技
- 引用数据只用公认可查的事实；无把握标「待核实」；绝不编造精确数字
- 弹药里的例证是构造出来的通用场景，**原文锚点永远来自被分析文本**

## 第一式 · 类比迁移

**原理**：谬误的推理形式是通用的。把论证的**深层结构**抽出来，放进一个生活场景，荒谬立现——听者自己就能完成定罪。

**构造四步**：
1. **抽象结构**：把论证化归为「前提类型 → 操作 → 结论类型」的骨架
2. **搜索同构域**：在家庭 / 职场 / 交易 / 游戏 / 交通等日常域里找结构相同的场景
3. **检验**：两个场景只共享深层结构，不引入新变量（新变量会引发"那不一样"的反驳）
4. **一句成稿**：压进一句话，不求全

**质检**：听者零解释成本；替换前后结论荒谬度落差大；不开启新战场。

**失败模式**：表面相似（只共享皮相不共享结构）→ 被反手定为不当类比；战火转移（听者开始争论类比本身）。

**范例骨架**：「X 提供了 Y 所以要感激 X」→ 迁移：「乱丢垃圾还给保洁提供了就业呢」。

## 第二式 · 平行替换

**原理**：不换域，只换对象——把对方的推理**原封不动**套到另一个主体上，让荒谬自己显形。

**构造两步**：
1. 保持推理逐字不变，只替换主语 / 对象
2. 替换对象选**无争议的中性对象**（换了它对方没法恼羞）

**质检**：推理一字未改（改了就是稻草人）；替换后结论明显荒谬。

**范例骨架**：「父母是普通人，不该被要求太多」→ 替换：「司机是普通人，上了路不必守交规」。

## 第三式 · 经典案例

**原理**：用该谬误的**标准出处**或著名典故举证，权威感与画面感兼备。

**用法**：按谬误编号到 [canon.md](canon.md) 检索；优先选与被分析文本语境亲和的（中文语境优先中国典故）。

**纪律**：只讲与断裂点相关的部分，不整段复述典故。

## 第四式 · 数据锚点

**原理**：用公认统计事实对照个案与直觉，把"我觉得"压回"实际是"。

**三类锚点**：
- **基率对照**：先问基础概率，再看条件概率（千人算一遍）
- **比率 vs 绝对数**：对方用的是哪一种？换算后结论还成立吗
- **回归均值**：极端表现后的回落是自然规律，不是干预的功劳

**三档纪律**：
1. 公认可查 → 直接引用
2. 方向对但数字没把握 → 写「方向成立，具体数字待核实」
3. 不掌握 → **不引用**，换别的弹药

## 第五式 · 反例构造

**原理**：一个满足对方全部前提、但结论明显为假的情形，胜过十句理论。

**构造三步**：
1. **固定对方前提**（钢人后的版本，不是稻草人版本）
2. **构造场景**：严格满足每一条前提
3. **指出结论为假**：落差点越直观越好

**强度**：一个就够。堆多个反例反而显得不确定。

**失败模式**：反例偷偷修改了前提——那是给自己造稻草人。

## 第六式 · 概念澄清

**原理**：把被偷换概念的两种含义并排放，让读者亲眼看到"前提说的是甲，结论说的是乙"。

**两种用法**：
- **定罪用**：并排两义，标出断裂点（配合 reconstruction.md 的「四种偷换手法」定位）
- **建设用**：给出固定定义后，**替对方重述一遍论证**——很多"谬误"在概念固定后自动消失，这部分不进清单

## 第七式 · 归谬法

**原理**：全盘接受对方的大前提，代入一个无争议案例，推出与常识或对方其他立场冲突的结论——大前提即塌。

**构造三步**：
1. **接受**：全盘接受大前提，一字不改
2. **代入**：选一个对方**无法拒绝**的案例（越日常越好）
3. **引爆**：指出推出结论的荒谬处

**质检**：代入案例无可拒绝；结论冲突直接可见、不需要解释。

**失败模式**：归谬变稻草人（"接受"时偷偷改了前提）；归出的结论只是"不太优雅"而非"荒谬"。

## 第八式 · 证明过多（Proving Too Much）

**原理**：归谬的近亲——若同一前提能同样"证明"一个对方绝不敢接受的命题，该论证的证明力即存疑：证明得太多，等于什么也没证明。

**构造三步**：
1. **接受前提**：全盘采纳对方的前提，一字不改
2. **扩大适用域**：把前提套用到对方绝不敢接受的场景
3. **并置**：两个结论放在一起，让对方任选其一

**质检**：扩域后的结论必须是对方明确无法接受的（不是你不喜欢的）；域的扩展要有结构依据，不是硬扯。

**失败模式**：扩域后推出的命题对方其实能接受——那不是证明过多，是你扩错了域。

**范例骨架**：「好处的事必被垄断」→「锻炼也有好处，怎么，跑步还要门票解锁？」

## 选弹策略

| 听众 / 场景 | 优先弹药 |
|---|---|
| 普通听众、社交场景 | 类比迁移、平行替换、归谬（零术语） |
| 专业场景、书面分析 | 数据锚点、反例构造、概念澄清 |
| 教学、穷尽模式 | 八式全上，展示构造过程 |
| 实战回复（反驳卡片） | 归谬 / 平行替换二选一，一击即走 |
