# 论证重构方法论（第 1 步 · 钢人重构的完整操作）

找谬误之前，先把这段话**写成最强版本**。本文件是重构的完整操作手册：语域判定 → 找结论 → 列前提 → 画论证图 → 补省略前提 → 澄清概念 → 产出论证还原卡。

## 0. 语域判定（一切之前）

**先问：这段话在承担论证功能吗？**

- 判定依据：有无可辨认的「结论 + 理由」结构；语境线索（脱口秀 ≠ 评论区论战 ≠ 产品文案）；用户的分析意图
- 文本类型速判：
  | 类型 | 适用标准 |
  |---|---|
  | 论断 / 评论 / 辩论 | 完整论证标准 |
  | 玩笑 / 修辞 / 抒情 | 只拆"被当作论据使用的部分" |
  | 营销 / 宣传 | 拆断言与暗示，豁免夸张修辞 |
  | 仪式性表达 / 客套 | 不进谬误清单 |
- 产出：**语域标签**，决定后续严格度。语域判错的定罪全部作废。

## 1. 找结论

- **指标词**：所以 / 因此 / 这说明 / 这意味着 / 可见 / 显然 / 综上所述
- 无标记时问一句：**这段话想让我信什么、或做什么？**答案就是结论
- 多结论拆开分别处理；结论没明说时显式化，并标注「隐含结论」

## 2. 列前提

- **指标词**：因为 / 由于 / 毕竟 / 既然 / 你看 / 要知道
- 每条前提标注类型，类型决定后面用什么弹药拆：
  - **事实断言**（可查证）→ 可能是事实错误，不算谬误
  - **例子 / 个案** → B1/B2 系
  - **类比** → A3 检查
  - **权威 / 人多** → E 系检查
  - **价值主张** → 不是谬误材料，标价值分歧

## 3. 论证图（承重分析的地基）

画出两类箭头：

- **支持关系**：前提 → 结论
- **攻击关系**：前提 ← 被对方反驳的点（辩论文本用）

关键区分——**独立前提 vs 合作前提**：

- **独立**（各自足以支持结论）：拆掉一个，结论还站着 → 全是装饰性
- **合作**（合起来才够）：拆掉任何一个，结论悬空 → 全是承重 ⚠

这一步直接决定总评里的承重标记，不要跳过。

## 4. 补省略前提（钢人操作的核心）

日常话语几乎都是省略三段论——有一块板没搭。补全三步：

1. **找断裂口**：从最后一条前提到结论之间，"跳一跳才够得着"的那块板
2. **最善意补全**：按最有利于说话人的方式把板补上（宁可补强不可补弱）
3. **检验**：补全后论证成立吗？
   - 成立 → 此处无谬误，撤出清单
   - 仍不成立 → 断裂点就在补全后剩下的那一步，照样定罪
   - 只有补上「循环 / 虚假」的前提才能成立 → 这个前提是对方论证的真实代价，定罪对象就是它

## 5. 概念澄清术

**四种偷换手法**（对照文本找）：

1. **指称漂移**：同一个词，前文指甲、结论里指乙（「自由」从财务自由滑到时间自由）
2. **内涵-外延切换**：定义上说的是一类，例证里换成了另一类
3. **整体-部分滑动**：整体的性质摊给个体，或个体的功劳揽给整体
4. **描述-评价混同**：把事实描述悄悄换成道德评价（「讲价」变「算计」）

**固定定义三法**：

- **必要充分条件法**：写出被分析概念的充要条件，两边对照
- **操作化定义法**：把抽象词换成可观察的行为指标
- **边界案例法**：构造两个极端案例逼出边界（什么算 / 什么绝对不算），边界一立，偷换即暴露

## 6. 产出：论证还原卡

```
结论：……（显性 / 隐含）
理由：① ……（独立 / 合作）② ……（类型：事实断言 / 例子 / 类比 / 权威 / 价值）
隐含前提：……（最善意版本）
概念边界：X = ……（固定后的定义）
语域：……（严格度：高 / 中 / 豁免修辞）
承重预判：拆掉哪条，结论塌
```

后面所有步骤都以这张卡为地基。
